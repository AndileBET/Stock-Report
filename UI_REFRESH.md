# Stock Intelligence UI Refresh — Vetra-inspired Enterprise Edition

This edition keeps the existing upload, search, date filtering, regional drill-down, variance, request comparison and executive multi-export workflows intact while replacing the visual system.

## Visual direction
- High-contrast editorial layout inspired by modern animated SaaS interfaces.
- Dark graphite command rail with mint/lime operational accents.
- Warm off-white analytical workspace for maximum readability.
- Large, tighter display typography for boardroom readability.
- Dark premium command-centre hero with moving orbital telemetry.
- Animated KPI entry, hover elevation, row staging and ambient background fields.
- Clear green operational states, coral risk states and restrained blue/gold supporting chart colours.
- Stronger hierarchy for panels, tables, filters, multi-selects and report export controls.
- Responsive layouts and `prefers-reduced-motion` support.

## Runtime dependencies
No additional runtime dependency was required for the refresh. Motion is implemented with GPU-friendly CSS so the local dashboard remains lightweight and does not call external animation/font services.
